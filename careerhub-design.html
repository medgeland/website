02 / Trade-offs

Options rejected.
Decisions made explicit.

One universal dashboard

Role-specific shells

A student is trying to move forward; an employer is making selections; the Career Center is managing exceptions. Sharing data is valuable. Sharing navigation is not.

Chosen because permissions and task density differ by role.
AI writes the CV

Coaching without authorship

AI CV Tailor analyzes clarity, structure, ATS readability and evidence gaps. Its prompt explicitly prohibits rewrites and ready-made application text.

Chosen because the student must remain the author.
Permanent “AI-written” warning

Conditional integrity signal

A warning appears only when the analysis returns a real robotic-language signal. It invites review; it is never presented as proof of misconduct.

Chosen because uncertainty should be visible, not weaponized.
One opaque CV score

Prioritized, explainable feedback

The result separates readability, language and evidence, then surfaces three next actions. A student can see what to change and why.

Chosen because actionability matters more than a magic number.

12 components · Storybook

Зачатки системы—not a finished system.

The existing product had reusable patterns, but no formal design-system governance. Storybook makes the foundations inspectable: buttons, badges, navigation, cards, progress, upload, feedback and AI states.
